      GitHub 연결

      연결 상태를 확인하는 중입니다.

      토큰을 한 번 등록하면 이 화면에서 바로 발행·수정하고 그림을 붙여넣을 수 있습니다. 토큰은 이 브라우저에만 저장되고 GitHub(api.github.com)로만 전송됩니다. 등록하지 않아도 "발행"을 누르면 내용이 채워진 GitHub 화면이 열려 Commit만 누르면 됩니다.

      토큰 만드는 방법 (1분)
      1. GitHub의 토큰 만들기 화면을 엽니다 (Fine-grained token).
      2. Repository access에서 Only select repositories를 고르고 {{ site.repository }} 하나만 선택합니다.
      3. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다. 다른 권한은 필요 없습니다.
      4. 만료 기간을 정하고 Generate token을 누른 뒤, 나온 값을 위 칸에 붙여넣고 연결을 누릅니다.

      이 토큰으로는 이 저장소의 파일만 고칠 수 있습니다. 공용 PC에서는 등록하지 말고, 필요 없어지면 "연결 해제"를 누르거나 GitHub에서 토큰을 삭제하세요.

      Zotero 연결

      연결 상태를 확인하는 중입니다.

      읽기 전용 키를 한 번 등록하면 "Zotero에서 가져오기"를 쓸 수 있습니다. 키는 이 브라우저에만 저장되고 Zotero(api.zotero.org)로만 전송됩니다. 아이패드에서 쓰려면 아이패드 브라우저에도 한 번 등록합니다.

      키 만드는 방법 (1분)
      1. Zotero의 키 만들기 화면을 엽니다.
      2. Personal Library에서 Allow library access와 Allow notes access를 켭니다. Allow write access는 끈 채로 둡니다.
      3. Save Key를 누르고, 나온 값을 위 칸에 붙여넣은 뒤 연결을 누릅니다.

      아이패드에서 한 표시가 보이려면 Zotero 앱의 동기화가 켜져 있어야 합니다. 손글씨는 GitHub 연결이 되어 있을 때 쪽별 그림으로 올라갑니다.
